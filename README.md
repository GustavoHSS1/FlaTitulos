1. Contexto
O projeto consiste em um dashboard esportivo focado na visualização e catalogação histórica de títulos de um clube de futebol.

2. Público-Alvo
Perfil: Torcedores entusiastas e historiadores esportivos. De todas as idades que tenham o minimo de conhecimento de internet.

Usuários que querem fazer consultas rápidas durante discussões esportivas ou acompanhamento de histórico.

3. Dor Principal
Atualmente, o usuário encontra dificuldades em visualizar de forma centralizada, cronológica e categorizada todos os títulos do clube, muitas vezes precisando recorrer a múltiplas fontes de pesquisa ou tabelas complexas e não interativas.

4. Critério de Sucesso
O usuário consegue filtrar e visualizar os detalhes de qualquer título histórico do clube em menos de três interações na tela.

## Arquitetura do Projeto

O projeto segue a metodologia ITCSS para organização dos arquivos CSS, separando estilos em camadas:
- Settings
- Base
- Layout
- Components
- Utilities
